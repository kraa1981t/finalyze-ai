═══════════════════════════════════════════════════════════════════════════════

الاختبار 1: عميل جديد
───────────────────────────────────────────────────────────────────────────────
1. افتح متصفح جديد (Private/Incognito)
2. اذهب إلى: https://finalyze-ai.vercel.app
3. سجل دخول جديد: اضغط "Sign in with Google"
4. → يجب أن ترى نافذة API Key modal
5. اختر: "Create free Google Gemini key"
6. انسخ المفتاح والصقه
7. اضغط Save
8. → النافذة تغلق والموقع يفتح ✓

الاختبار 2: دخول لاحق
───────────────────────────────────────────────────────────────────────────────
1. اخرج من الحساب (Logout)
2. سجل دخول من جديد بنفس البريد
3. → لا تظهر نافذة API Key ✓
4. → يدخل مباشرة للموقع ✓

الاختبار 3: صفحة مراقبة العملاء
───────────────────────────────────────────────────────────────────────────────
1. سجل دخول كمطور (dev account)
2. اذهب إلى: Settings → Client Monitor
3. → يجب أن ترى العميل الجديد في القائمة
4. → البريد الإلكتروني محفوظ بشكل صحيح
5. → الحالة = "active"
